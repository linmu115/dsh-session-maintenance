# Maintenance 0.2.19 看板入口修复与启用

2026-09-06 12:18（北京时间），已在 DSH **0.1.2-rc.1 / web** 启用插件 0.2.19。Engine 保持 0.1.16，SCM 保持 0.3.2，Launcher 与数据库配置未改动。

## 原因与修复

设置页“打开完整看板”及可选侧栏自动携带当前原生会话 ID，后端将请求解释为“打开该会话的看板”。当前 ID 不属于活动投影运行时，身份解析返回 `Session is not mapped in this active projection run`，于是全局入口被阻断。

两个全局入口现均不传会话 ID。右键菜单继续按冻结的原生会话目标定位；没有放宽身份检查，也没有自动建立或改写映射。

此前启用检查直接调用了不带会话参数的 Dashboard 接口，未覆盖设置按钮附带当前会话的路径。本次回归执行实际设置按钮与真实 RestrictedEngineProxy，在合成 Engine 响应中先复现同一错误，再验证修复。
