# 同步实例目录使用 Launcher 名称

用户反馈 Maintenance 同步页实例过多，无法与 Launcher 对应。真实只读检查返回 6 项，Launcher 当前只有 4 项。旧实现把所有历史运行实例 ID 与静态注册项合并，未读取 Launcher 名称；未运行的新实例也没有出现。

修复后日常选择器使用当前 Launcher 实例与名称，刷新体现新增、改名和删除。历史运行与未关联登记默认折叠；稳定 ID 继续用于请求和保存，同名附带 ID 区分，重复 ID 或损坏目录明确报错。目录读取不做接入探测、绑定或业务写入，旧同步策略、冻结范围及 ID 查询保留。

候选版本为 Engine **0.1.33-rc2.54** / Dashboard **0.1.14**；同时补齐已发布 Maintenance 插件 rc2.33 的接入版本白名单。

验证：6 个测试文件、22 项目录/同步/HTTP/UI 组件测试通过，另有 32 项发行接入与运行证明测试通过，两组无重复文件。Contracts/Engine 构建、Dashboard 类型检查及生产构建通过。发行包 Dashboard HTML 与当前生产构建逐字节一致。新实现读取真实 Launcher 配置与只读数据库，返回 4 个当前实例名称及 3 个历史/未关联项，没有修改数据库或同步策略。

发行包已生成，尚未切换运行版本。当前 RC2 副本有活动托管 run，需用户通过 Launcher 正常停止后核验关闭回执，再备份并更新 Maintenance。源码、只读验证和组件测试不能代替已部署或实机 UI 验收。

开发历程：从真实接口与 Launcher 配置比对定位历史目录混用，分离日常项与历史项；覆盖新建离线实例、改名、同名、重复 ID、目录异常和历史配置保留。当前会话来源索引待绑定，过程草稿不冒充正式可展开历史证据。
