# GPT 插件会话格式独立适配

用户要求：将 GPT 兼容插件使用的会话格式支持实现为独立 Adapter，再提交两个项目并同步项目及系统地图。此前部署通过重新打包 Maintenance、替换全局 DSH 读取依赖完成联调；它不属于独立 Adapter 的正式接入。

实现目标：普通 V3 Adapter 保持原有事件词表；`dsh-gpt-compat` 注册独立格式身份，复用 V3 的物化、追加和恢复机制。插件事件由自己的 codec 校验，完整保留专用状态与序号。未知版本、缺少插件能力、错误引用和格式身份不匹配必须拒绝。

验收包含独立注册与选择、普通/插件适配器隔离、原生文件往返、追加和恢复、拒绝无效事件以及并发调用不串用词表。验证结果随实现完成补充。

## 已完成

- 新增独立包、Adapter ID、formatId、codec 与 RPC worker。普通 V3 的公开入口继续使用原词表；通过每次异步调用的作用域复用底层逻辑。
- 验证五类插件事件及引用，保留不透明状态；完整物化、追加、压缩文件和耐久尾部恢复通过。
- 组合根、Launcher 实际 bundle 发现、构件回执、Broker、请求索引与原生证据均路由到独立适配器；Core receipt 显式选择格式身份，旧回执保持普通 V3。
- 引擎版本 0.1.33-rc2.29；发布器包含独立 worker。修复打包 worker 中 DSH LLM 读取相对 package.json 的问题，并将其纳入可移植性运行检查。
- 项目地图补充“插件扩展会话格式先构建 Adapter”的权威合同与专属实现记录，保留既有地图拆分和稳定 ID。

普通 V3、插件适配器、Core 与接入共 116 项相关用例通过（先运行 114 项，再新增并重跑插件/接入的 41 项）。Engine、Core、新 Adapter 类型检查通过。发布包生成通过；独立提取的 Engine 可执行，GPT worker 正确返回自己的身份。可移植性检查覆盖 41 个产物文件；10 项发布合同测试通过。两张项目地图的记录/关系校验无错误、无警告。

当前 GPT 插件独立仓库的 51 项离线测试、类型检查和构建也通过；可选 live 测试跳过。本次未发起真实账号调用。

## 部署边界

这次提交完成源码重构和发布接线，不替换正在运行的副本引擎，不覆盖已钉住的 Core dist。现有副本仍为之前全局依赖替换的联调部署。后续升级应先停止目标、备份、重新构建并钉住 Core 格式回执、修复接入后重启；旧真实 CPA 验收不是新 Adapter 的部署证据。全仓构建和实时多人/大窗口任务未作为本次验证结果。
