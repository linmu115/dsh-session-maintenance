# 扩展归属与会话阅读器交付记录

本次解决扩展 namespace 卡片分散、对象缺少所属会话目录，以及会话阅读器把运行上下文和大量工具记录直接铺开的情况。需求见[规格](../superpowers/specs/2026-09-15-extension-ownership-and-session-reader.md)。

## 变更

- 业务 Adapter 聚合面板，实例与 profile 筛选，按真实工作区成员关系逐层展开会话和条目。上游来源不再被误当成条目所有者；不明确的旧归属单独待核验。
- 可重建的所属会话索引，元数据分级分页，正文按选中读取；披露记录从主干图展开。内部 namespace、版本冲突和图领域写入保护继续生效。
- Annotation Core 提供受限的只读条目目录与持久化后通知；Maintenance 插件通过当前运行身份映射同步轻量镜像。离线、未映射或未收到持久回执时保留重试；明确删除才写删除状态。事务日志、完整文档与上游上下文不进入镜像。
- 新会话阅读接口只返回问答小页和过程计数。展开后读取过程目录，再按需读取具体记录；使用快照绑定避免跨页混入新修订。旧 canonical API、角色、原文与投影语义保持兼容。

## 验证与部署

Maintenance 完整类型检查与构建通过；Dashboard、目录、阅读器、上下文、图归档及同步桥相关回归共 27 个文件、129 项通过。Core、Suite 及配套插件分别执行目录同步和兼容测试。合成浏览器验证了深浅色、工作区与会话展开、选择引用详情、过程展开与折叠卸载。对现有 3 个 RC2 会话进行只读采样，新阅读接口按真实来源识别运行上下文与技能目录，首屏响应为 906–1424 字节，没有读取或输出完整会话正文。

本次验证不发送真实模型请求。运行副本安装采用成对 Engine/plugin、19 个已安装成员的完整兼容检查、新宿主探针和独立备份。schema 23 → 24 只允许新增归属索引表及其索引；安装前后核对原始 canonical 事件、不可变版本、会话头摘要，部署凭据写在任务独立 artifacts 目录，不复用旧版通过回执。

目标版本：Engine 0.1.33-rc2.19、Maintenance 插件 0.2.26-rc2.15、Core 0.3.12-rc2.10。配套成员仅追加对新 Core 版本的明确兼容：Sticker 0.7.3-rc2.16、Sidechat 0.4.7-rc2.10、Lifecycle 0.3.3-rc2.14、Reference Adapter 0.3.4-rc2.14、Suite 0.3.4-rc2.16；ThoughtDAG 保持 0.4.14-rc2.8。

## 数据边界

索引迁移仅增加派生目录表，不改写既有会话或扩展正文。普通旧贴纸仍遵守原有的迁移激活回执规则；这次不绕过该规则搬迁 Vault。引用镜像只读，原业务入口继续负责编辑、删除与恢复。未接通的插件保留既有数据，不因离线或分页缺席而清除。
