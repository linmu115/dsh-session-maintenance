# 思维图边界对齐、连续切换与副本验收

日期：2026-09-15。已安装并通过 Launcher 启动 DSH 0.1.5-rc.2 副本的 web Profile。

## 使用与可见变化

会话页顶栏的“对话／思维图”开关仍在原位。思维图的上横线和左竖线依据原生会话页实际边界对齐；调整侧栏宽度、折叠到 56px、改变标题宽度或窗口尺寸时重新测量。窄窗口通过“主干导航”抽屉选择主干，打开导航不会推动画布。

切换采用 180ms 透明度过渡，画布内容轻移 4px，两条边线和开关保持静止。动画中反向点击会接续当前进度，不排队播放。启用系统“减少动态效果”后立即切换。

空画布可直接添加空卡片或按工作区选择已有会话，加载期间显示实际读取状态。画布角落显示卡片和连接数量，“图示与操作”按需展开。右键菜单不会超出视口，支持方向键、Home、End、Tab 和 Escape；关闭时恢复触发位置的焦点。菜单内 Delete 不会误删画布对象。

已有主干归属、固定来源截止位置、上下文披露和引用撤销规则保持。刷新已打开的副本页面即可载入新版；Obsidian 内嵌页需要重新连接启动后的副本。

## 动画开销

同一个 iframe 和画布在反复切换中复用，不为每次动画重新加载。关闭时立即停用可见状态刷新，淡出完成后隐藏。仅在过渡期间保留合成层提示；没有新增永久动画循环、逐帧宽高调整或全画布模糊。几何变化按动画帧合并，相同样式值不重复写入。

节点测量时可能短暂不可见，菜单焦点恢复只在关闭时重试，最多 200ms；新菜单、弹窗、用户主动转移焦点或卸载会取消恢复。这不是常驻轮询。

这些处理限制了新增动画的工作量。没有测量用户 Obsidian 窗口的实际 GPU 帧率，也没有据此宣称此前偶发卡顿已经修复。
