# 扩展归属目录与会话阅读器

日期：2026-09-15。状态：用户已确认并授权实现；本规格更新 2026-09-10 可拔插扩展数据需求的展示与归属规则。

## 业务 Adapter 与所属会话

扩展数据显示一级业务 Adapter 面板。Obsidian 系列汇总注释、普通贴纸、独立会话贴纸、跨会话引用、Obsidian 引用和笔记关联；ThoughtDAG 汇总会话主干图及其披露记录。内部 namespace、写入方、兼容性检查、对象版本和领域操作继续独立管理。实例与 profile 使用筛选器，不能因实例或 namespace 数量增加而重复一级面板。

面板按“工作区 → 所属会话 → 业务条目”折叠浏览，沿用当前会话阅读器的 logical_workspaces / workspace_memberships 归属，包含父子工作区；不通过执行目录字符串猜测工作区，也不使用独立的项目分组覆盖它。条目只有一个所属逻辑会话，其他会话是来源或关联：

| 条目 | 所属会话 | 来源关联 |
| --- | --- | --- |
| 普通注释、贴纸 | 绑定会话 | 可选的选区来源 |
| 跨会话引用 X → Y | 接收引用并执行的 Y | X |
| 从 X 创建独立会话贴纸 Y | Y | X 的蓝色引用标记导航至 Y |
| Obsidian 引用、笔记关联 | 接收或绑定的 DSH 会话 | Vault 笔记或块 |
| 会话主干图 | ownerSessionId | 图中上游会话节点 |
| 披露记录 | 主干图所属会话 | graphObjectId 指向的主干图，作为附属记录展示 |

所属关系由对应 Adapter 解释明确字段。references 数组不是所属关系，禁止取数组第一项当所有者。没有明确归属的旧对象放入默认折叠的“待绑定／待核验”；未分配工作区的有效会话归入“未分配工作区”。移动会话后，条目自动跟随当前会话归属。索引可重建，不能为重建目录改动原对象 revision。

目录只加载元数据。展开工作区加载会话，展开会话加载条目，选择条目才加载正文。列表分页，切换筛选后取消过期请求。图的披露记录不能与图并排冒充独立主干。各成员分别显示连接、停用或不兼容状态，部分可用不等于整组可写。图结构仍在 ThoughtDAG 领域接口中修改；已有归档、撤销与恢复规则不变。

## 引用条目接入

Annotation Core 的实时引用事务仍由 Core 管理。新增有界的轻量条目导出与 Maintenance 镜像，不复制完整 aggregate、外部文档快照、提交 journal、outbox 或模型上下文。每项仅保存稳定身份、选区和评论的有限摘录、来源定位、状态、Core 修订与所属会话。超长摘录明确标记截断。

由当前运行绑定将原生会话 ID 解析为逻辑会话 ID。映射尚未建立时重试，禁止把原生 ID 当逻辑 ID。启动补齐和运行变更采用幂等同步，仅明确的删除记录可以删除镜像，插件停用、离线或分页暂未返回不能当作删除。较旧修订不能覆盖新状态。镜像条目在看板只读，删除和恢复继续从业务入口执行。

## 会话阅读器

真实用户正文与最终回答保持直接可见；同一轮运行上下文、技能目录、推理、工具调用与结果、系统记录汇总为一个默认折叠的“本轮过程”入口，显示分类与数量。工具调用按身份配对结果。连续系统记录不能生成一排空白气泡。

展示分类使用平台 Adapter 解析的可信原始 source，而不是根据英文句子或 XML 标签隐藏内容。用户自行输入相同文本仍是用户正文；混合正文保留可确认的用户部分。仅添加查询与展示语义，禁止修改 canonical kind、role、content 或投影可见性。

关闭过程组时不挂载隐藏的 Markdown 或 JSON。展开才请求有界过程目录，进一步展开具体记录才加载正文或原始证据；大结果分页读取。跨页绑定固定版本和有效快照，切换会话或版本取消旧请求。既有完整 canonical API 为其他消费者保留兼容，新阅读器使用有界 API。

## 验收条件

1. 多 namespace、多实例仍各显示一个 Obsidian 系列和 ThoughtDAG 业务面板。
2. X → Y 的引用只在 Y 目录出现，X 作为来源；会话贴纸同理。
3. 工作区、会话、条目分层按需读取；未知归属不误分配。
4. 工作区迁移不需要重写扩展正文；重建索引不增加对象版本。
5. 主干图下可查披露记录，图领域写入保护和成员启用状态保持有效。
6. Core 当前引用、状态变更和明确删除同步；离线保留、重试幂等、旧修订不倒灌。
7. 镜像无完整文档或事务日志，不形成逐轮快照仓库。
8. 运行上下文和技能目录默认折叠，真实用户粘贴相同文本保持可见。
9. 用户正文、最终回答顺序正确；工具与结果在一轮过程内可查。
10. 折叠时没有隐藏正文渲染；长工具结果只在展开后分段读取。
11. 深浅色、窄窗口和键盘展开正常，切换后旧响应不污染当前目录。
12. 安装到 0.1.5-rc.2 副本验证，原会话真源、引用提交和图归档规则不受展示变更影响。
