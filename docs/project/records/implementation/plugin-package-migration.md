2026-09-19 用户要求将 RC2 副本的全部插件迁移至新建 RC2 测试实例；发现 Maintenance 安装文件与旧 rc2.29 安装包不一致后，进一步要求从最新源码重新打包、使用新包并提交推送。

核对发现安装中的客户端文件与当前源码工作树既有构建结果 SHA-256 相同。当前源码已是 rc2.32，旧安装清单仍固定于 rc2.29；新发行使用 rc2.33 区分这次完整源码重建。先完成构建、插件测试、类型检查与隔离安装，然后部署到已停止的测试实例。

迁移保持测试实例自己的稳定 ID、home 和宿主依赖。源实例运行期间不替换其插件，不迁移历史会话、运行日志、Vault 绑定或同步策略。业务启动与 UI 验收单独记录，不以包校验成功替代。

交付结果：测试实例已安装全部 19 个插件及支持包，Maintenance 使用源码重建的 rc2.33；插件 1,161 个文件及独立引用界面配套组件 63 个文件逐项校验通过。27 个测试文件、123 项测试、类型检查、构建和严格 peer 安装通过。源插件 1,165 个文件、Launcher 目录配置和目标原有凭据/存储文件未变；测试实例保持停止，真实运行与 UI 未验收。

开发历程草稿：最初为复刻已安装文件制作了保留差异的隔离候选；用户要求改为正式源码包后，放弃将该候选作为最终交付，转而重建完整插件并发布独立版本。原会话来源索引待绑定，不将此草稿标为正式可展开历史证据。详细结果见 `docs/reports/2026-09-19-plugin-package-migration.md`。
