2026-09-19 用户反馈新建 Vault 绑定的文件夹窗口数分钟才出现，并已发生超时。要求选择器及时打开；尚未打开和等待用户选择应分别处理；取消及失败不应造成绑定写入。

候选 Engine 0.1.33-rc2.55 改用 Common Item Dialog，从本机用户目录开始；启动 20 秒、目录初始化后人工选择 10 分钟，断连取消辅助程序。保留原有 Vault/Bridge 身份验证、CAS 及幂等绑定流程。

17 项针对性测试和类型编译通过，独立本机初始化约 1 秒且存在窗口句柄。已安装仍为 .54，存在活动实例而未切换；前台显示、真实文件夹选择及绑定 UI 未验收。不得将开发测试状态当作实际安装状态。

开发历程草稿：经用户迟到弹窗反馈，区分独立诊断窗口和正式操作；排除 PowerShell 基础加载慢，将问题定位范围缩小到旧 Shell 选择器后续阶段，并以新选择器和分阶段期限改善。原 Windows 延迟的详细根因未确认，来源索引待绑定。证据与部署进度见 `docs/reports/2026-09-19-vault-folder-picker.md`。
