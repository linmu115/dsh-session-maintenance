Engine 0.1.33-rc2.55 改用 Common Item Dialog，从本机用户目录开始；启动 20 秒、目录初始化后人工选择 10 分钟，断连取消辅助程序。保留原有 Vault/Bridge 身份验证、CAS 及幂等绑定流程。

17 项针对性测试、32 项发行接入测试和类型编译通过，候选包已完成构建，独立本机初始化约 1 秒且存在窗口句柄。用户正常停止后，确认 closed 回执和旧引擎 drain / owner-release，备份维护数据再激活 .55；测试和副本均 connected。浏览器已打开测试实例的绑定面板，新建入口可用、绑定数 0。文件夹窗口前台显示、真实选择及绑定提交仍未验收，不用后端检查代替此边界。
