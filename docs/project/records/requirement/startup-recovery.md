# 点击启动即可恢复安全可回收的旧运行

来源：2026-09-19 用户确认“就这样改”，并确认修改只放在 Launcher 与 Maintenance 生命周期；任务 `01a0b3f3-cfc5-7783-a99b-5e345935f435`，公开来源见 [[HIST-startup-recovery]]。

- 启动时检查目标实例旧运行。能证明进程已退出，自动执行既有正式恢复流程，成功后继续启动。
- 恢复期间显示简短进度；旧进程仍活跃、无法确认退出或恢复失败时才提示具体原因。
- 保存运行进程身份和退出证据；端口不通或根 PID 消失单独不构成回收依据。
- 保留现有 UI、其他插件的业务功能、Vault 绑定、同步名单及会话数据。
- 验收区分旧运行正式恢复、完整启动流程、进程身份登记、构件保护及视觉检查。测试和健康接口不代替真实界面验收。
