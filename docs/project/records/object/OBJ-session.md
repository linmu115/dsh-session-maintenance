# 逻辑会话、源版本与运行空间

用户看到的是工作区里的会话。底层用逻辑身份把原生会话、规范事件、不可变版本、检查点和运行回执关联起来。运行空间按实例、profile、分支与格式隔离。

导入 Codex 是建立可维护的来源；开始同步是后续动作。引用固定一个源版本与已完成回复截止。接收会话首次实际追加才产生派生分支，来源更新不覆盖接收会话已有回答。

来源、运行投影与恢复记录有不同职责。不要把旧目录的同名文件当成当前会话，也不要通过修改真实 Codex/DSH Home 验证地图。
