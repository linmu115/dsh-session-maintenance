# 这张地图选了哪些资料

## 选择规则

1. 以 2026-09-16 当前 RC2 工作区 README、成员清单与实际源码入口解释现状。精确分支、提交和绑定文件摘要见 source-baseline.json。
2. 保留可解释用户意图的 09-10 主干/引用规格及 09-15 归属、阅读器、原生上下文修订；09-14 核查中的“缺口”要结合后续实现重新判断。
3. 模块和使用说明直接绑定原有 Markdown 的唯一标题，不重新复制整份需求书。
4. 只挑解释关键边界的历史验证；报告对应当时版本。旧 RC1、旧本地所有权、重复发包记录和个人会话原文不作为当前需求灌入。
5. 无实现证据不写“已完成”；未获确认的建议不写成需求；已退役功能不列待办；没有失败探索证据就不凭空制造探索档案。

## 来源的优先级

明确的新用户决定及对应修订优先；当前实现说明与合同帮助判断落地程度；旧测试只说明原版本当时结果。矛盾尚未解决时标出差异，不能由地图自动选定较乐观说法。

## 跨项目

外部依赖只有项目 ID、记录 ID 和必要原因。本机登记负责找地图位置；不复制另一地图全文，不因为引用关系自动扫描所有工作区。组合地图绑定的成员文档仍在各自仓库维护。
