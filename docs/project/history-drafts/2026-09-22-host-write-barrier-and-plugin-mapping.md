# 2026-09-22：宿主写入屏障与插件功能恢复

整理者：当前任务 Codex。来源范围为本任务用户对“通用图模型”的否定、要求补齐宿主独占写入，以及“插件 adapter 映射回去得到功能保持”的补充；未导入其他会话，尚未绑定正式事件索引。

用户把核心职责收敛为忠实保留插件数据及来源，插件 adapter 自己握手并恢复可用功能。本轮先保存这项修正，再实现通用映射注册表及宿主内的完整写回操作。宿主采用实际持久化组件的内核锁和正常 flush/close，避免远端租约超时后调用方仍直接写文件。

实际组件测试发现 Cordis 对方法自动绑定，按取值比较包装函数会误报屏障被替换；改为核查自有属性描述符。缺插件时省略记录会改变目标序号，随后反向读取不能再按原始逐行前缀比较，因此加入适配器拥有的投影回执与追加事件坐标映射，保留原插件记录和新增载荷。最终接口复查又补上目标会话和宿主上下文，以两会话隔离回读验证恢复位置。

类型检查暴露上一轮阅读器测试的字面量推断，以及本轮 schema 可选字段与严格可选类型的差异，均已修正。组合回归 340 项通过，最终局部复核 31 项通过（部分重叠）；全工作区类型检查和构建通过。未部署真实实例，真实业务插件恢复尚未验收，遗留核心图/引用耦合尚未清理完。
