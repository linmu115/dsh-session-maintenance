# 独立会话贴纸创建修复

## 问题与行为

RC2 的普通运行中会话可以省略 delegationDepth，官方 JSONL 写入器会补零。扩展显式保留新会话及事件上报直接传递内存头，Maintenance 的严格 V3 校验因此报出 `format v2 header lacks required field delegationDepth`（V3 校验复用了 V2 头校验）。

在 RC2 持久化适配端口集中补齐缺省 delegationDepth，再执行官方严格校验，显式会话登记和常规事件上报使用同一转换。不修改内存会话对象，不放宽已保存格式的验证；已有非零深度保留，非法值拒绝。

新增 create-workspaces 操作，分页列出当前实例的原生 WorkspaceRegistry，包含空工作区。create-session 必须提供已存在的原生 workspaceId，调用官方会话控制器完成创建和工作区挂接。不得将 Maintenance 的逻辑项目 ID 直接传给原生控制器。操作及工作区共同决定幂等身份；部分创建失败重试时再次调用控制器，修复未完成的挂接。

## 验证

- 用缺少 delegationDepth 的合成运行中会话头复现官方错误，修复后通过官方 V3 写入及恢复，验证不修改输入、不覆盖非零深度、不接受非法深度。
- 工作区必选、已删除工作区拒绝、空工作区和分页、重复及部分失败创建重试均有测试。
- 同步修正兼容性测试中遗留的 rc2.3 插件版本断言为当前 rc2.11；RC2 宿主 ABI 精确断言保留。
- 发布使用相同兼容队列下独立路径的本地构建包，只安装至 0.1.5-rc.2 副本。引擎和原生宿主无需改动。
