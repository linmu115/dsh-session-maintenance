# 阅读目录与项目映射显示收尾

日期：2026-09-06

## 范围与行为

仅调整 Dashboard 的阅读目录及同步页显示。

- 阅读侧栏递归隐藏没有会话的空工作区分支，保留承载非空子孙的全部祖先。此操作仅作用于前端树，不改数据库、项目归属或工作区 membership。
- 工作区搜索不会重新显示被裁剪的空目录；搜索祖先名称可展开其非空子树，搜索会话标题仍保留到该会话的祖先路径。
- 同步页当前活跃名单和最新已保存名单默认显示项目名；目录卡片的来源实例、Codex 项目标识、稳定 key 均置于原有的折叠“项目详情”。目录暂不可见项也将原始 key 放在详情中。
- 同名项目按完整 key 排序后显示简短编号，编号不随搜索、勾选改变；详情保留精确身份。React key、选择集合及保存请求仍使用真实项目 key。
- 生效时机文案统一为“下次启动 DSH 实例”，对应实例 prepare 时激活名单，避免让用户误以为需要重启长驻 Maintenance Engine。
- 保持原有目录顺序，避免勾选时列表跳动。未修改版本、构建产物或部署状态。

## 验证

- canonical-workspace-model：空根、空子分支、深层非空子孙祖先保留、输入目录不变。
- reading-dashboard：空工作区不显示，搜索会话保留祖先路径，搜索空目录无结果，搜索祖先显示子孙，阅读选择保持。
- codex-project-mapping：默认名称与折叠详情、同名编号、真实 key 保存、搜索/取消/刷新行为回归。
- 聚焦测试共 3 文件、30 项通过；Dashboard 类型检查通过。

所有测试使用合成 fixtures。本次未执行 build、部署或版本提升。
