# DAG 会话数据 adapter 与统一存储边界

DAG 不再因安装 Maintenance 而切换到 maintenanceGraph。宿主会话数据层通过可选 sessionExtensionSync/v1 端口恢复和同步；adapter 仅转换身份、格式与提交回执，不维护自己的业务数据库，不执行 DAG 增删规则。

图 adapter 按实例/profile 隔离，旧 schema 2 已绑定主干可按会话恢复，后续提交为 schema 3；旧对象保留。Core 控制本地持久化、修订冲突和写入许可。未注册实例独立使用；注册实例失联仍停写。端口停用不删除数据。

3 项 adapter 测试覆盖旧图转换、保留原件、冲突/删除标记，以及通过 Core 数据层保存后替换本地存储再恢复。相关 10 项引擎目录、3 项写入许可、1 项扩展列表测试通过。DAG 与 Core 的对应改动分别在其源码树，合计 40 项针对性测试通过。

本轮 Engine .57、接入插件 .35 已打包；实际部署注册被旧插件版本白名单阻断（只到 .34）。按用户要求停止，不将合成验证记作真实 WebUI 或用户引用验收通过。后续需修正发布版本识别与完整注册验收。
