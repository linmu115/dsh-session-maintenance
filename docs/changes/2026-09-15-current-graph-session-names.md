# 主干图的会话名称投影

Engine 0.1.33-rc2.26 / Maintenance 插件 0.2.26-rc2.22 配套 ThoughtDAG 0.4.14-rc2.13。

旧图将创建时的会话名称直接保存为对象标题和节点 label；会话标题补齐或重命名后，图的读取没有核对最新元数据，导致持续显示历史 ID。

现在 ensure、load、save、bind、remove 的返回结果以及扩展对象列表使用最新会话名称。图文档按节点的稳定会话身份批量读取逻辑会话元数据；列表查询限定当前实例、profile 和本页对象。未绑定草稿与非会话卡片的自定义名称保留。没有可读名称时用“未命名会话”，不显示机器 ID。

这属于只读展示投影，不重写既有对象，不改变对象修订、来源版本、连线、截止位置或权限。会话页重命名后，已保存图在下次读取时自动更新。

合成测试验证旧 ID 修复、重命名、列表一致性、无存储写入、无布局变动和材料名称保留；接口回归覆盖现有固定版本读取、引用解除与实例隔离。副本运行状态以本批独立部署与在线验证回执为准。
