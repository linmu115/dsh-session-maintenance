## 实现

1. 宿主回传队列将新通知与历史失败重试分离。限制每批报告数，历史失败不能占满队列；纯失败重试退避，新事件可立即唤醒。归档/删除差异优先处理，后台观察间隔 5 秒。插件快照单条失败不阻断其他会话。
2. RC2 adapter 使用释放观察租约的 point observation 读取继承日志及追加尾部。阅读器从保留的原始事件恢复正文；未知结构化数据仍完整保存并折叠，客户端 DTO 校验不再使整篇会话不可读。
3. 宿主屏障绑定真实 Cordis 服务与 idle agent owner，先完成 flush/drain，再持有内核和插件写入锁。真实持久化日志领先待写版本时拒绝覆盖；不把阅读视图合成的中断收尾误判为真实尾部。
4. 同一端点的原生会话保留其原生 ID，旧派生副本不能反向覆盖原会话元数据。标题投影产生的额外序号只从校验过的回执恢复，后续续写、归档仍可重新映射。
5. 插件数据恢复前先校验，Lynn 的已知空字段只用于兼容比较，原始数据保持原样；核心不加入插件业务分支。GPT adapter 保持独立。
6. 变更后刷新宿主持久化阅读缓存；移动时先从落盘头刷新 RC2 工作区索引，再挂接目标工作区，避免旧 cwd 缓存拒绝移动。
7. Maintenance 会话页可见时定期更新目录，当前会话版本改变时刷新正文；请求重叠与卸载取消均受控。保留“编辑 → 勾选 → 保存/撤销”。
