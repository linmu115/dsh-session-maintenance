# ThoughtDAG 已移除画布目录与材料版本保护

日期：2026-09-14。修复 P3 画布移除后无法从插件目录找到对象、因而不能恢复的问题。

`MaintenanceExtensionBridge.list(namespace, after?, deleted = "active")` 增加可选的 `"active" | "deleted" | "all"` 查询范围，透传到既有 Engine 扩展对象列表。默认仍只返回活动对象。ThoughtDAG 可以请求全部元数据，再按前端回收列表选择显示；不读正文、不删除真源会话。

跨会话捕获增加可选 `expectedSourceVersionId`。当画布预览后源会话改变，新的引用创建须在 Engine 写入协调期间核对用户选定版本；读取完成位置之后、保存对象之前再次核对。版本不一致直接失败，不创建幽灵关系。对同一幂等操作的重试核对原记录版本，允许复用此前成功捕获的同一版本，不悄悄改指新版本。未提供这个字段的既有跨会话入口保持原语义。

验证：host URL 单测核对默认值、分页和实例范围；真实 Engine 合成测试覆盖保存、移除、默认隐藏、查询已移除/全部和恢复；跨会话 HTTP 测试覆盖新操作版本不一致不创建对象、原操作同版本重试与不同版本拒绝。三个文件共 11 项测试、workspace 类型检查通过。未发布或部署。
