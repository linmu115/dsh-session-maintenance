# RC1 元数据恢复与维护气泡隐藏

Engine 0.1.27 / RC1 adapter 0.1.3 / Session Maintenance plugin 0.2.22。
基于已部署 Engine 0.1.26 的源码与部署记录继续修改。

RC1 原生标题、模型、权限、沙箱、审批、inbox 和 dsh-runtime/detail 记录被误归入
MCSF other；重启投影后变成维护气泡。现在这些确切事件类型作为原生元数据保留，
跨执行环境的可移植历史仍不携带本机策略。Codex detail 恢复原事件，由其所属插件渲染。
真正未知记录留在数据与诊断中，Maintenance 不再为它们注册聊天节点；兼容导出的旧
渲染器也返回 null，避免重载期间留下气泡。

历史修复仅发生在读取投影时：通过 adapter 的可选 restoreNativeEvents 接口验证
原始 evidence 的归属、格式、类型、序号和 envelope；未知类型、缺少证据、可移植
历史不恢复。证据冲突拒绝恢复。Engine 不包含 RC1 字段知识，完整读取、差量读取、
固定版本读取使用同一适配视图，保持投影前缀校验一致。canonical 版本不被重写。
适配器版本变化会使旧投影缓存失效，下一次正常启动重建。

验证：工作区构建成功；11 项定向测试通过，覆盖两个重启往返、历史证据恢复及拒绝、
三种读取路径、缓存和未知记录不可见。真实测试会话的只读验证中，63 条 other 全部
可恢复，原始 canonical 数据未变。未进行压力测试或真实会话写入测试。

生效：前端气泡隐藏需要重载新插件；元数据恢复需要新引擎及下一次会话投影。
引擎为 Launcher 共享服务，不能在 DSH 会话仍运行时强制替换进程。
