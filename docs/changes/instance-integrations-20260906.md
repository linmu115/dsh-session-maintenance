# 实例接入管理 · 2026-09-06

候选版本：Engine 0.1.17 / DSH 插件 0.2.20；配套 Launcher 0.2.3。基线为 Maintenance 9d2279b、Launcher 47b2d5d。部署中的旧发行包未被此施工覆盖。

## 已实现

设置页从 Launcher 的 config.json 发现实例，按真实 instance ID、home/version ID 和 profile 建立稳定目标；不以版本名或目录显示名推断实例身份。首批允许已验证的 Alpha2、RC1 和 web 配置；Maintenance 插件只允许 0.2.19 / 0.2.20。实际 CLI、会话组件、Web bundle、插件入口与 bundle 声明/补丁必须存在并通过检查。

包按实际导入者解析，bundle 遵循官方 CLI 安装位置优先、profile 次之的顺序；结果必须留在选中 Home 或版本目录内，不能误用祖先目录中的同名开发包。无法识别的自定义核心组件替换不宣称兼容。两层用户 cordis.patch.yml、额外 bundle 和关键版本/路径进入指纹；无关损坏 profile 只使自身不可用。

接入与修复调用所选实例的官方 plugin add，设置其 DSH_HOME、profile、工作目录与 Launcher pnpm store。Engine 发行包内嵌同版插件 tgz 和摘要，安装前校验。慢速安装不占用 Canonical 全局写队列；共享 profile 的接入操作互斥，超时终止自己创建的安装进程树。安装后重新发现、检查 Adapter，再短暂进入写队列发布 Hook 与绑定。失败不发布绑定；已安装文件可以保留，后续修复可重试。

Hook 只接管经 BUILD-INFO 或 Engine 包身份确认的已有 Maintenance 提供者；保留经过摘要核验的 SM-13 trace 包装。未知提供者和包装不被覆盖。新 Hook 使用 --require-binding，prepare 只处理匹配的实例与 profile；未绑定对象不连接 Engine、不创建投影。旧手工全局 Hook 的行为保持到用户显式接入采用新模式为止。

Launcher 发布协议、四阶段、进程 PID、实际 exe 路径和 SHA-256。Engine 独立检查存活进程的程序路径与 hash；正常重启时 PID 不进入稳定绑定指纹。二进制摘要缓存由文件身份、尺寸、mtime/ctime 纳秒值失效。能力文件缺失、运行程序变化或配置变化时要求重新检查/修复。

断开只移除对应绑定，保留会话和已安装插件。首次发现与安装阶段均有操作代次保护，断开完成后更早的接入不得重新发布绑定。已损坏的绑定仍显示“需要处理”并可断开。Hook/绑定发布异常时恢复本次写入的 Hook，不覆盖第三方后续改动。

Codex 卡片管理已登记来源，并从 Engine 可信启动环境的 CODEX_HOME（未设置时为用户目录下的 .codex）发现唯一默认来源。默认 Home 规范化真实路径后与已登记来源去重；目录不存在时不增加卡片，不兼容时明确显示不可用。使用真实 CodexReadAdapter 检查数据库和会话结构，显示“读取协议 0.146.0”，不据此声明桌面程序版本。

默认 Codex 首次接入在现有写队列内调用 addInstance，再发布绑定；仅保存 Maintenance 自己的来源登记，不创建原生回写目标。登记成功后更新组合层共享的来源数组及实例映射，当前 Engine 的来源列表和 Codex 导入立即可用。重复接入和重启保持幂等；断开保留来源、设置和会话。浏览器只能提交目标标识及操作，不能指定路径。传入合成 integrationEnvironment 而未指定 codexHome 时禁用默认发现，测试不会回退到用户 Home。原生回写仍不可用。

已有多个 ID 指向同一真实 Home 时，接入优先核对所选 ID 的平台、真实路径和读取协议，保留其它已登记别名；仅在所选 ID 尚未登记时阻止同路径重复新增。旧扫描服务也保留共享来源列表，单实例扫描立即识别新来源；整批扫描在开始时保存来源和 ID 快照，运行中新增来源不会扩大当前批次范围。

## 使用边界

接入前需要启动带能力发布的 Launcher；一个 Launcher 数据目录由一套运行宿主管理。网页接入状态代表已验证的配置与绑定，不代表 DSH 当前运行连接已经建立。真实 RC1 重启和完整发行包部署验收是后续发布步骤。

独占范围目前覆盖 Maintenance Engine 内的接入操作；不会锁住用户另外手动启动的 Launcher 包安装。安装后指纹复核会阻止改变后的配置发布绑定。未来若需要跨工具并发安装，需共享正式的安装任务锁协议。
