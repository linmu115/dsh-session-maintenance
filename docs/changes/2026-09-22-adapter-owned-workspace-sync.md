# Adapter 所有的工作区同步

## 用户要求与本轮范围

2026-09-22 用户要求继续实现，并明确：Maintenance 本体不耦合实例、Launcher 或其他插件；耦合只发生在 adapter。运行期同步按新建会话、追加对话、改名、移动工作区、归档和删除的完整范围推进。来源为本次 Codex 任务的用户消息和注释；未读取或改写原始会话日志。

主体拥有逻辑会话身份、版本、逻辑工作区选择、同步阶段、幂等操作与回执。Adapter 拥有宿主身份发现、工作区和会话格式、原生目录、宿主写入/归档/释放协议及扩展事件解释。装配层可以选择 adapter，但不得承担它的格式或宿主逻辑。

## 交付判据

- 普通运行不依赖 Launcher run 也能通过实例作用域的同步命令回传。
- 启动对齐与运行期提交属于不同世代；未完成对齐不接收运行期变更，旧世代请求不得重放。
- 身份解析、作用域检查与提交在同一写入协调范围内；范围外会话不改写。
- 新旧映射都能幂等登记，临时解析失败不丢失待处理变更。
- 所有平台格式及物理工作区读写归 adapter；核心的通用协议使用 contracts 中唯一 DTO。
- 用合成宿主和 API 组合测试验证；真实实例安装及写入验收单独记录，不用健康检查代替。

## 已完成的源码改动

- 通用核心：`EndpointSyncCoordinator` 管理 aligning / active / blocked、每次对齐的独立 epoch、策略版本检查及串行提交。身份解析、范围检查、提交在同一写入协调范围内，profile 在提交时重新核验。
- 规范历史：`reconcileEndpointSession` 只接受规范事件和元数据，保留旧版本及已有前缀，支持新建、追加、标题、归档和工作区变化；拒绝陈旧版本、截断、删除后自动复活及只读外部源续写。重复相同内容不创建新版本。
- 平台适配：五个原生目录/写回文件移入 `packages/instance-integration-dsh`，Engine 原路径仅留兼容导出。工作区路径和原生快照读取归 adapter，核心不读取 cwd、seq、宿主归档列表或插件事件名称。扩展事件通过现有 GPT adapter catalog 组合处理。
- 身份与路径：新增和已存在映射都登记绑定，重复登记保留已有共同版本。工作区路径按身份保存；只有匹配当前端点来源的实际路径才能复用，不能凭同名认领；重排和重命名不改变已保存路径，冲突路径拒绝复用。
- 宿主上报：读取 RC2 实际的 header/revision 快照；普通运行无需 Launcher run。关闭浏览器仍观察内容与元数据变化；首轮 active 刷新补偿对齐与观察之间的空隙；短暂错误保留待办，新 epoch 清除旧待办及删除基线。删除遇到会话重新出现时取消旧删除意图。
- API：新增有身份与范围的 sync-state / sync-changes，archive 布尔值不再被代理白名单拒绝；运行期命令携带观测 epoch，范围外返回明确的跳过回执。
- 对齐保护：实际解码比对原生内容，不再仅凭旧标记判断未变化。缺少 adapter 独占写入协议时，在触碰宿主文件前拒绝对齐；归档变化缺少宿主恢复接口或回读不一致时不能成功。启动对齐有阶段门槛，关闭 Engine 等待已有对齐结束。

## 未完成项与下一步边界

1. **真实宿主独占写入协议未接通。** 当前生产装配没有 `withWriteAccess` 提供者，所以新对齐会明确 blocked；不能部署后声称同步可用。必须由 adapter 接入经过核验的 flush / drain / exclusive write / release 流程。Launcher 外部停止协议未核验，不能以直接 shutdown、杀进程、删锁替代。
2. **宿主取消归档尚无已核验接口。** 私有标记只用于维护记录，不是宿主回执；当前没有真实 `synchronizeArchived` 提供者。需在 adapter 完成双方状态恢复及回读验收。
3. **派生会话与只读外部源续写未补齐。** 序号压紧、原生引用重映射及跨格式派生仍需专项实现；当前规范协调器明确拒绝覆盖只读外部真源，不能把此拒绝当作完整续写功能。
4. **未分配工作区、空事件会话、真实扩展附件往返仍需专项验收。** 当前原生刷新依赖明确映射的工作区目录；本轮合成通过不覆盖这些组合。
5. **整个 Engine 的遗留耦合仍存在。** 本轮只完成同步路径的职责拆分。`apps/engine/src/integrations/service.ts` 的安装/Launcher hook 编排、`composition-root.ts` 的既有插件业务初始化等尚未全部抽象为 adapter 端口；用户提出的全局架构要求不得标为完成。

真实安装版本和用户已有未提交改动保持原状。此提交是可审查的同步开发候选，不是双向同步功能的完成验收或发布。
