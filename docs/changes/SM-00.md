# SM-00: packaged Dashboard entry verification

Date: 2026-09-05. Baseline: `0333e18`, containing Dashboard discovery `a6b4053`
and the identity/deletion and official RC1 blank-session fixes in `4b49927`.

The independent integration worktree installs its own frozen workspace links;
it does not resolve development packages from the running primary checkout.
The 20 Dashboard/authentication/identity/deletion/RC1/proxy baseline checks pass,
the workspace build passes, and the built Dashboard boundary test passes.

The Engine+Dashboard portable candidate was produced with the standalone
packager. This avoids the separate legacy Canonical Generation packager, whose
baseline currently describes an Alpha2 composition with external plugins.

`scripts/verify-dashboard-entry.mjs` verifies the actual Engine archive in a
marked temporary fixture. It extracts only contained package paths, starts the
packaged CLI with an explicit synthetic state root and unrelated working
directory, and leaves out `--dashboard-root`. It checks index/application
availability, authenticated health, unauthorized API rejection, one-use launch
code exchange, UI cookie/bootstrap and authenticated overview, then takes the
CLI's normal signal shutdown path. No model request or real instance is used.

Verification command after building and packaging:

```powershell
node scripts/verify-dashboard-entry.mjs .artifacts/sm00-dashboard-candidate/dsh-session-maintenance-engine-0.1.14.tgz
```
