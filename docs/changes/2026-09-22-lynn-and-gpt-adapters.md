# Lynn adapter 与独立 GPT adapter

来源：本任务用户要求先收尾宿主同步和主体解耦，再将任务 `01a0c759-8c96-7460-bcbd-d4bf40512308` 的插件组合接入一个综合的 Lynn adapter，gpt-compat 独立适配，完成后更新当前引擎供用户启动实例验收。

组合以指定任务的当前源码为准：Core .28、Bridge .10、Companion .8、普通贴纸 .11、ThoughtDAG .27；Sidechat 不在该任务确认的组合内。插件仍独立运行，合并的是 Maintenance adapter。Lynn 内部按成员握手，缺成员仅保留其数据、不映射。

验收原则：Maintenance 不解释插件业务模型；原始数据及来源忠实保存。Adapter 将数据恢复到当前插件实际读取位置，按正确目标身份映射并回读验证。外部 Vault 笔记和机器绑定不是会话副本，不因会话恢复自动重绑定或批量改写。

实施范围：不透明附属数据随会话同步，成员功能握手及正常读写验证，独立 GPT 事件恢复，迁出遗留插件业务入口，发行包构建校验；随后备份、正常停止/更新 Engine，并核验实际安装状态。另一任务正更新测试实例，安装阶段须等待其完成，不并行改同一实例。

实现完成：Engine **0.1.43-rc2.71**，实例接入组件 **0.2.27-rc2.45**，Lynn adapter **0.1.0**，独立 gpt-compat adapter **0.1.0**。实际安装回执单独记录，不把构建版本当成运行版本。

维护主体以不透明原数据、类型来源、版本及同步回执为边界。插件附属记录纳入 schema 29，支持版本固定与派生基准继承，缺失不作为删除。图、引用、知识服务及对应路由迁入 adapters/lynn，旧路径仅兼容转发；宿主阅读格式通过 reader provider 注入。裸核心可运行且不加载 Lynn 服务或路由。

Lynn 从真实 Core、会话扩展数据与贴纸服务取得数据。插件运行状态与实际可用的写入屏障共同构成握手；采集作稳定性检查，恢复时重写目标身份、图节点/边标识和贴纸修订，在插件原读取位置回读验证。目标缺插件、未知扩展类型保留而不投放；用户在采集后新增的编辑不会被旧快照覆盖。已迁出到 Vault 的历史贴纸归属标记不擅自复活；跨实例引用缺少目标映射时明确拒绝，不猜测会话身份。

GPT 事件独立识别、握手、恢复与读回；过滤/派生后检查点及操作结果引用随目标序号重映射，悬空或向后引用拒绝。宿主 adapter 负责排空写入、真实原生写锁、归档/取消归档、刷新状态和释放访问权。Maintenance 身份通过完整声明定位物理 profile，拒绝重复声明，解决 web-i27c4 与 profiles/web 不同名的问题。

验证：全仓 typecheck、build 通过；最终连续回归 **88 个测试文件、416 项测试全部通过**。当前实际 Core / Sticker / DAG 组件在隔离合成数据上通过 AnnotationStore.readPending、LocalSessionExtensionData.list、ThoughtDAG.ensure、StickerLocalStore.read 验证；源数据不变、未知保留、缺插件跳过、并发编辑保留均通过。所有测试均未把用户真实会话当作测试样本。

交付包含独立 Engine 启动、打开及正常停止脚本。发行位置由 Maintenance 自身的 engine-installation.json 决定，不依赖 Launcher 生命周期配置。Engine 可单独更新；运行中的实例接入组件必须等 Launcher 正常停机后再替换。当前 Launcher 没有已核验的外部停止入口。

真实连接和 UI：留给实例升级后的启动验收，**未验收**。组件回验与健康接口不代替真实新建、续写、改名、移动、归档/取消归档、删除及插件功能往返验收。
