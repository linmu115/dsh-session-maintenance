# 可拔插扩展数据实现

Engine 0.1.31 / 插件 0.2.24 / 数据库格式 22。

Maintenance 现在提供独立扩展数据域和动态管理面板。画布、引用集合及知识链接
通过稳定身份关联会话，编辑插件对象不会生成或改写会话消息。此次实现遵循
`docs/superpowers/specs/2026-09-10-pluggable-extension-data-requirements.md`。

## 实现

- contracts 统一定义对象、版本、引用、能力、配置报告与冲突协议。
- SQLite 三张扩展表保存接入配置、当前对象、未解决冲突；无逐轮快照或无界编辑备份。
- ExtensionDataService 独立注册/卸载 Adapter，检查实例/profile 配置、插件版本、
  schema、写入权和能力。内置 ThoughtDAG、Annotation、Obsidian 链接格式校验。
- Engine 受保护接口与客户端方法覆盖分页读取、启停、带预期版本的保存、删除恢复
  及显式冲突处理。DSH 宿主通过可选配置接通服务；浏览器不获得 Engine 凭据。
- 看板“扩展数据”按已报告的数据域显示面板，先读元数据，选中才读正文；保留缺失
  能力提示、关联会话入口、编辑、回收站和冲突处理入口。
- 存储维护继续读取格式 21，同时识别格式 22 的恢复点，不把新格式误判为未知。

## 范围与接入说明

详细协议、示例、空间约束及接入责任见
[`../extensions/plugin-data-integration.md`](../extensions/plugin-data-integration.md)。
已确认的 ThoughtDAG 后续魔改和旧插件事件迁移仍单独进行；没有部署 ThoughtDAG、
扫描原生历史来伪造画布，或自动搬迁现有 Annotation/Obsidian 数据。公共宿主桥接
已通过真实 Engine HTTP 测试，第三方业务插件还需把保存入口接到该桥接。

## 验证

- 合成隔离数据库验证不同对象格式、跨会话引用、重复保存、版本冲突与重试、显式
  冲突解决、删除恢复、实例/profile 隔离、65 对象分页、缺少 Adapter、卸载重装、
  重启后保留、大小/冲突上限和只读能力。
- 真实 Engine HTTP + 官方 Maintenance 客户端 + DSH 宿主桥接联通测试覆盖认证、
  列表、保存读取、禁用写入和未配置数据域拦截；来源 fixture homes 哈希不变。
- 看板组件测试验证按接入情况显示、分页元数据、缺失能力时不加载正文。
- 回归、构建、类型检查与打包验证结果随发布包验收记录保存。真实用户实例没有
  被用于创建测试画布或测试注释；用户人工验收不计入自动验证。

发布前结果：最终专项 18/18、相关回归复测 37/37、工作区构建和类型检查通过；
打包后的插件加载/卸载和 Engine 看板认证/退出检查通过。首次全库运行覆盖 819
项，其中 809 通过、10 项失败：旧导航断言、历史迁移 fixture 未移除新表、临时
产物误入可移植性扫描、新增可选宿主依赖的提前加载，以及测试运行期间增补能力
注册断言造成的缓存不一致。上述问题已修正并由相关复测与隔离打包检查覆盖。
