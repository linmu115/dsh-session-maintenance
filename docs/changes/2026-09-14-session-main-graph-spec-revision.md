# 会话主干图需求修订

日期：2026-09-14。范围：文档；不修改插件代码、运行配置、安装包或真实数据。

## 问题与变更

原规格和现有维护版 ThoughtDAG 包含无主干归属画布、纯知识线、只移除呈现、常驻局部问答和全局维护网络，与用户确认的“每会话主干、按需上下文传导”目标不符。

更新两份统一规格，并新增功能取舍核查：

- [设计和功能需求](../superpowers/specs/2026-09-10-session-context-graph-requirements.md)：加入右键对象操作、延迟绑定空卡片、X → Y 图归 Y、来源高亮与蓝色引用符号、撤销后停止读取和刷新不复活；移除全局网络、影响及批量重答需求。
- [插件与引擎改动清单](../superpowers/specs/2026-09-10-session-context-graph-plugin-changes.md)：补充当前实际入口、统一关系操作、轻量位置日志、Maintenance Adapter/schema/兼容登记联动及 W09–W15 实施顺序。
- [功能取舍核查](../superpowers/specs/2026-09-14-session-graph-feature-scope-audit.md)：区分用户确认删除、必要保留、额外建议和未被 DSH 加载的上游独立能力。

日志区分“允许读到哪里”和“本次实际返回哪些范围/从哪里继续”，图只存身份、位置、计数和状态；固定上限、并发预算与防循环规则保留。新增 AC23–AC40，更新 AC15 的删除语义。
