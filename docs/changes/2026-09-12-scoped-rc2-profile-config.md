# Admit the verified RC2 onboarding configuration

Actual integration discovery rejected ordinary loopback Web configuration and the Maintenance instance/profile settings as infrastructure replacements. RC2 discovery now recognizes strictly shaped loopback Web settings and Maintenance settings whose instance/profile match the discovered target and whose source is Maintenance.

Disabled components, replacement implementations, foreign scope, native bypass, persistence-root changes and duplicate infrastructure insertion remain refused. Earlier runtime adapters retain their previous inspection contract. Focused tests cover both the actual target configuration and the refused mutations.
