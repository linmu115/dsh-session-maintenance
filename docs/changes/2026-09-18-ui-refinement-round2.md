# 会话目录与 Vault 绑定页面精简

会话工作区和项目默认折叠，未归类组也可折叠。目录仅显示名称，不再重复会话数量或根路径；搜索仍自动展开匹配的路径。主导航选中状态改为中性灰。

Vault 绑定页去重标题、操作按钮不再放入重复边框卡片；在线状态与Vault名称优先显示。实例ID/完整绑定记录和使用说明可展开，长绑定记录优先展示原提供方的绑定状态。保留所有操作描述符、请求修订与幂等回执逻辑、离线禁用和重试语义。扩展分类命名/慢加载由独立功能任务同步处理。
