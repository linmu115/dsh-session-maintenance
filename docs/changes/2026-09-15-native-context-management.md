# 原生 Agent 主干与上下文管理

本次实现 2026-09-15 补充规格 W19–W24 的代码、组合测试与发布接入。执行范围为 DSH 0.1.5-rc.2 原生 Agent；未新增托管引擎工具或改动托管运行实现。

## 使用

在接收会话的思维图中，右键来源卡片选择“管理来源上下文”。先查看请求目录或某轮问答，再选择需要保留的一个或多个区间。窗口的扩大不会自动加载正文。暂停阻止新读取；释放清理后续模型输入中的材料；解除连接撤销引用并同步图和来源标记。

原生 Agent 会获得九个工具：`dsh_graph_inspect`、`dsh_request_list`、`dsh_context_status`、`dsh_context_window_set`、`dsh_context_release`、`dsh_context_source_set`、`dsh_context_pin`、`dsh_graph_edit`、`dsh_context_discover`。已有上游 read/search 工具增加 `userRequestId` 定位。模型只操作自己的执行会话，不能通过参数指定其它主干或扩大固定授权。

默认用完材料时释放它，图边及来源定位继续保留。按来源释放只放弃该来源的持有，共享材料要到最后一个持有者释放才移除；按材料句柄整体释放会影响它列出的所有持有者。模型不能释放用户固定项。来源归档、撤销或不可用时，保留标记不恢复读取授权。

Maintenance 阅读页的“用户请求索引”默认折叠，DSH 停止时仍可查询当前规范版本。扩展状态仍按 Obsidian 系列 / ThoughtDAG 两个业务面板、工作区和所属会话展示。`annotation-context` 是引用业务域中的对象类型，不是第三个面板或独立数据库。

## 实现边界

- 版本 Adapter 识别真实提交、执行边界和来源角色；系统运行材料、技能目录、引用包和释放记录不伪装成用户请求。长请求分页，索引不复制回答和工具正文。
- 授权版本及截止、活动窗口、实际保留材料分别维护。窗口使用规范事件身份，支持整轮边界及不连续片段；读取返回前重新核对暂停、撤销和窗口代次。请求目录仍索引整个已授权上游，便于选择其它窗口。
- 模型图编辑通过有范围限制的领域操作完成。图、引用与操作回执在同一同步存储事务内提交，异步身份检查在事务前完成；失败后不会留下半条连接。循环检查只遍历有界的结构化关系，不加载其它会话正文。
- Core 使用原生 `surfaceOp: replace` 及 `sourceEventSeqs` 追加替代事件；初始问答和工具结果按条目处理，保留其它来源、用户评论、工具调用身份及协议配对。原始事件不被覆写。
- 宿主先 flush，再登记材料或提交生效回执。Adapter 用官方 v3 校验和 surface 折叠检查真实持久事件、材料摘要和局部替代，Engine 使用核验出的字节差，忽略宿主声称的释放量。
- 中断后使用同一操作身份恢复。重叠释放有独立证明；日志裁剪不使旧材料重新登记。材料登记受限时明确显示待登记数量，已有释放操作仍能执行。
- 累计读取额度和当前输入占用分开。释放不返还额度；请求索引与正文读取共享持久预算。模型状态/发现页按返回页容量上限保守计入同一持久额度，控制回执保持有界且不会因读额度用完而禁用释放。
- 用户预览不占 AI 本轮额度，不登记模型材料，不写成模型已读。历史读取覆盖与当前保留使用不同字段；覆盖截断时明确标记。
- 能力按当前实例、Profile、插件版本和启停状态协商。旧未配置实例保留原读取行为；已配置能力停用后不能绕过保存的暂停或窗口。无插件材料的普通会话可以继续；仍有保留材料或待注入引用时，恢复能力前暂停发出新请求。新工具仅挂在原生 Agent 的工具目录，遵守宿主策略、取消与卸载。

当前数据上限：一个接收会话最多 256 个来源、256 个材料句柄、128 条操作；状态正文最多 256 KiB。窗口最多 64 个区间。已完成的旧操作、已释放材料可以裁剪，未完成操作与活跃材料不静默丢弃。模型元数据页最多 4,000 字节；请求目录与正文单页最多 16,000 字节，由实际本轮额度继续收紧。字节测量不是精确 token 数，也不表示已发送请求可以被撤回。

| 验收 | 主要证据 |
| --- | --- |
| NCA01–NCA04 | Adapter request-index 与 Engine user-request-index-service：可信来源、用户补充、分页、身份稳定、旧快照游标拒绝 |
| NCA05–NCA06 | 100 轮来源固定到 40 轮、请求定位与不连续窗口；后端 window/pause/cursor 联合测试 |
| NCA07–NCA09 | Core 真实原生 AgentLoop 请求装配；Adapter 局部替代验证；Engine durable-loop 完整持久提交链 |
| NCA10–NCA13 | 暂停/恢复、统一解除、归属参数拒绝、主干锚点保留、反向循环拒绝、未完成来源拒绝 |
| NCA14–NCA16 | 冷恢复、重复/重叠释放、材料摘要与协议配对拒伪、共享持有及用户固定、跨域写入失败回滚 |
| NCA17–NCA18 | 持久额度跨服务重建测试，释放不返还额度；用户预览不登记模型披露；历史覆盖单独分页 |
| NCA19–NCA22 | 有界来源发现、来源失效、能力停用门禁、两业务面板、结构容量和裁剪保护 |
| NCA23–NCA24 | 原生工具目录、托管路径拒绝、执行身份与参数门禁、取消/卸载和真实 Host 契约测试 |

真实原生循环使用脚本化模型驱动，没有访问外部模型：首次请求包括来源正文，工具发起释放，下一次请求不再包括该正文，同时保留用户请求、评论和其它材料。完整 Engine 测试另外验证：未持久追加替代事件时拒绝成功回执；追加之后才通过；夸大的释放字节数不被接受。合成来源与输出保存在测试夹具中，测试不改真实会话或 Vault。

各仓库更细的实现记录见请求索引、持久证据、Dashboard 和 ThoughtDAG UI 的同日变更报告。副本安装还需要本批精确组合的独立安装、宿主验证和启动回执；本报告中的代码测试不代替真实部署回执。
