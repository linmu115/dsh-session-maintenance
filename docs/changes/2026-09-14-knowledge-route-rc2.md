# RC2 知识接口路由修复

实际副本验证发现：POST `/maintenance-knowledge/api/status` 没有命中插件路由，而落入静态页面回退，返回空的 405 响应。RC2 的 WebServer 给前缀自动追加斜杠，注册时应使用不带末尾斜杠的路径。

修正知识接口的注册前缀；增加使用官方 `@deepseek-ai/dsh-host-webserver@0.1.5-rc.2` 的实际 HTTP 测试，验证子路径成功、相邻前缀不会误命中。保留同源验证、请求额度和当前运行范围约束。

Maintenance 插件更新为 0.2.26-rc2.9，Engine 更新为 0.1.33-rc2.10；能力清单同步接受新版本。

验证：知识接口与版本证明相关 3 个测试文件、5 个测试通过；插件与 Engine 类型检查通过。副本在安装前经 Launcher 正常停止，530 条会话头指针保持不变，复用已验证的本次部署备份。

本修复属于会话贴纸、Vault 对象迁移和维护网络交付的实际副本验收；影响传播只生成候选列表，重新回答由用户确认发送。
