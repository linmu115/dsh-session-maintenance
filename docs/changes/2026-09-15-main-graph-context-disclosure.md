# 主干图引用接续与后端披露位置

实现对应 2026-09-14 经确认的会话主干图规格，目标为 DSH 0.1.5-rc.2 副本。

## 后端行为

1. 捕获或绑定跨会话引用时，以接收会话 Y 创建或更新主干图，方向 X → Y。ThoughtDAG 未启用时独立 Annotation 继续工作。
2. 新增固定引用描述接口。以当前运行实例和目标原生会话解析原引用，返回可恢复的来源身份；撤销、错误目标和不存在的版本均拒绝，不以最新来源替代。
3. 初始来源问答、工具读取和搜索在实际读取路径记录稳定事件范围、片段偏移、继续位置、预算计数和结果状态。日志不包含正文、搜索词或工具输出。允许截至位置与实际返回位置分别保存。
4. 宿主通过独立回执确认准备结果的交付。失败不能重新标记为已交付；请求期间撤销后返回被拒绝。布局版本与日志版本独立。
5. 知识入口代理权威来源标记目录，供 Sticker Board 恢复来源高亮；全局 network/impact 入口移除。

## 验证

- 真实 Engine 与鉴权 HTTP 的合成场景覆盖固定版本、源会话后续追加、目标身份隔离、前端关闭时自动建图、首轮/搜索位置、交付与取消、图删除后拒绝读取；源环境文件树保持不变。
- 分页测试覆盖长中文/emoji 回复和搜索继续位置，日志使用稳定事件身份；检索扫描过的空白区不被当作已返回内容。
- 插件代理测试覆盖当前实例来源标记路径及退休全局操作拒绝。

完整主干领域、UI、版本组合和部署验收见本次联合发布报告。
