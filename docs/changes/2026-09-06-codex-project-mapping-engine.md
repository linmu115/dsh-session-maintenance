# Codex 项目映射与真源范围治理

用户要求只维护自行勾选的 Codex 项目会话文件夹，首次选择 Internship、计算机、国际象棋、Language、AI-for-Math 的本地会话。项目成员不能从 cwd 或工作区推断，Codex 原始会话不能删除。

## 实施边界

- Adapter 读取桌面项目目录及显式成员，理解 server 项目迁移状态，保留同名不同 ID。目录不完整或归属冲突时暂停导入和清理。
- Engine 单独维护已保存与已生效名单，保存采用 revision 检查。下次实例准备阶段先核查所有旧运行已停止，再执行受限导入、可恢复清理和策略激活。
- 启动阶段使用同一个 SQLite 事务；规范化版本提交和项目 roots 写入允许在已有事务中使用局部 SAVEPOINT。导入失败回滚已写入的前缀、绑定、项目、版本、清理和策略。已写入内容寻址文件无需覆盖；无引用对象由既有存储治理处理。
- 保留真实来源 ID 关联的会话、DSH 派生后代以及所选项目内的 Maintenance 原生会话。旧 server ID 到 desktop ID 的已验证别名同时迁移会话分组，退休项目 roots 不参与新会话匹配。
- 范围外会话使用 tombstone 和集中恢复点移除，自动恢复只识别映射自身的删除 operation ID；不复活用户另行手动删除的会话。手动恢复精确复活所属项目，下次启动仍重新应用名单。
- HTTP 服务运行期间约每两秒检查当前名单内的变化，未变正文不解析，纯标题更新不重读正文；启停可取消且不重入。保存的下一次名单不会被后台观察器提前采用。
- 旧扫描入口在已配置模式下复用受限导入服务，在线与离线导入不能绕开名单。原生回写工作区配置保持独立。

## 验证与发布

新增合成测试覆盖空选择、同名/同 cwd 排除、归属及 revision 变化、坏的未选文件、增量观察、取消、重启、手动恢复、DSH 派生保留、嵌套版本写入及失败回滚。测试仅读写有标记的合成目录。

本版 metadata schema 为 21；发布时保留旧数据库和独立备份，用新副本迁移后再切换配置指针。实际数量、源码提交、产物摘要和实机检查另记部署回执。
